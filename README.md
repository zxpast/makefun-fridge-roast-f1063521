## What it does

`main.ts` (Node 22, standard library only, deterministic, no network) writes
a single roast line about a fridge to `/output/entry.txt`:

> My fridge's crisper drawer holds carrots I bought to impress a date who never came back — the carrots outlasted the relationship.

## Run

```sh
node main.ts
cat /output/entry.txt
```
